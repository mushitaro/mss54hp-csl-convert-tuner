# 2400 rpm の推定差の切り分け

> 本文は比較用推定器の調査記録であり、当時の未実装事項を含む。
> その後に実装したブラウザTune・BIN出力と、記録968の有限更新の結果は
> [64-moving-response-tune.md](64-moving-response-tune.md) を参照。

2026-10-12。対象は記録時 VE 0.841 の RO 7.5% / 2400 rpm。
実装は `analyze-response-influence.py`、`ve_controller_bounds.py`、
`analyze-response-identification.py` と、後述のP動作を扱う噴射量復元。
ログ・BIN・行別結果は非公開の `archive/` に保存する。
ブラウザの Tune/BIN 出力へは未接続。以下の倍率は pre-rf_korr 基準空気の条件付き推定である。

## −26.2% と −2.7% は同等の観測結果ではなかった

Session 968 の全制約、固定した輸送モデル flow-0.25-mix、変更抑制係数0.4での結果:

| 操作 | 2400 rpm 倍率 | 変更率 |
|---|---:|---:|
| 全通過を使用 | 0.738138 | −26.19% |
| 最後の時間分割を学習から除く | 0.973041 | −2.70% |
| 1747.52〜1763.24秒の通過の対象セル寄与だけを除く | 0.971794 | −2.82% |
| 上記以外の各通過を一つずつ除く | 0.737795〜0.738458 | 約−26.2% |
| O₂読取りだけを使用 | 0.738380 | −26.16% |
| I動作時間の下限制約だけを使用 | 0.831902 | −16.81% |
| バンク1だけを使用 | 0.783613 | −21.64% |
| バンク2だけを使用 | 0.763019 | −23.70% |

全フィット時の対象セルの観測勾配は0.104745。そのうち上記の通過が0.104205を占める。
目的関数の停留条件は `sum(X_ij residual_i) = 0.4 * (1 - f_j)`。
主要通過を除くと左辺の減量根拠がなくなり、変更抑制項が f を1へ戻す。
**−2.7%は別の走行区間がその補正量を積極的に示した値ではない。**
同じ理由から、時間分割ごとの倍率の最大値を保守的較正値にする処理は採用しない。

この通過の後半は2374〜2412 rpm、RO約6.4〜6.7%。7.5%セルの寄与は約0.59〜0.66、
残りは主にRO5%側である。燃料/基準空気比の約0.8という情報を、寄与0.6前後のセルへ
割り当てるため、セル単体では20%より大きい減量となる。O₂からAFR量を算出したのではない。
RO7.5%へ実運転点を固定した観測でもない。

## DMEのP動作に残っていた濃淡の情報

Slave `0x01D6A2` / `0x01DC42` は、P動作実行後にpending bitを消す。
再実行には符号変化による再設定が必要である。

- 1回のP動作は区間開始前に予約された可能性があり、その区間の両側の濃淡は保証しない。
- 同じ読取り区間で2回以上P動作が実行された場合、区間内に両方の符号が必要。
- 実行されたPの方向が交互である必要はない。逆向きの予約が実行前に上書きされても、
  その符号を通った事実は残る。

従って、P増分>=2の区間には濃い側と薄い側の `sample_envelope` をそれぞれ追加できる。
各側の発生時刻は未知なので、区間内のセル寄与と燃料比の極値を使った必要条件に留める。
I動作時間や、両バンク2周期の完了を要求する処理ではない。
967でもPカウンタは記録されているため利用する。TI/燃料カットがない967について
I動作時間を使うためにカット値を捏造することはしない。
RAM値の転送時刻の不確かさと、燃料再構成の仮定は依然として残る。

## 変更抑制項を除いて求めた範囲

新しい `feasible_range` は、入力した全不等式を満たす倍率の最小・最大を線形計画で求める。
目的関数に変更抑制項はなく、従来のフィット残差まで各観測の許容幅を広げる処理もない。
矛盾は `infeasible` として返す。観測を複製しても範囲は変わらない。

今回の対象分析は対象セルの係数>0.001の制約を抽出する。省いた制約は範囲を広げる側であり、
全域のマップが全ログを説明したという意味ではない。隣接セルは0.3〜1.7の範囲で同時に動かし、
バンク差は走行ごとに別の変数を許す。これらは条件付きの許容範囲で、信頼区間ではない。

以下は最初の**噴射量を直線補間したモデル**での計算である。後述の同時刻検査で
この入力モデルは不成立となったため、以下の狭い範囲を較正根拠には採用しない。
flow-0.25-mix、読取り中央、967の再構成燃料幅0の条件:

| 使用ログ | 2400 rpm の許容倍率 |
|---|---:|
| 968 | 0.6551〜0.7488 |
| 967 | 0.3000〜1.3939 |
| 968 + 967 | 0.6904〜0.7383 |

967単独では倍率1も許される。従来の「小さい減量案も別ログで悪化しなかった」は、
その補正量が正しいという検証になっていなかった。
共同条件の範囲も隣接セルとの配分を残しており、一点に決まったわけではない。

13輸送仮説×読取り開始/中央/終了×967燃料幅0/3/5%の117条件を別々に計算する。
不成立の仮説も出力から消さない。燃料幅は実測の誤差保証ではないので、
成立した仮説の範囲の合併を真のVEの保証範囲と読み替えてはならない。
`recommendedFactor` は未確定を表すnull、`calibrationStatus` はcomparison-only。

## 歴史データとの照合

D1から941/946のログ・BASE/TUNEDを再取得し、保存SHAを検証した。
同じセルは941 BASE=0.637 / TUNED=0.710、946 BASE=0.851 / TUNED=0.841。
現在の968 BASEは0.841。増加履歴は大きな減量方向と整合するが、
941にはO₂・Pカウンタ・各読取り時刻・TIがないため、0.637を正解のアンカーにはできない。

## 噴射量の直線補間ではP動作が消える

`analyze-command-reconstruction.py` はラムダRAMのSTFTとPカウンタだけから途中のSTFTを
推定し、構築に使っていない別の噴射ブロックの `injectionStft1/2` と照合する。
主な通過（行2671〜2685）の30点で、直線補間は最大0.019722（1.97ポイント）ずれた。
下記のDME更新量の範囲には30点とも入る。全走行の比較可能5757点では5754点が範囲内、
3点が範囲外（最大0.007666）。この3点を残差許容幅の拡大で成立したことにはしない。
行2539/Bank2、2572/Bank1、2705/Bank2には、未観測リセット・転送の非同期性等の検証が残る。

Slave `0x01D6A2` / `0x01DC42` のI/P更新則から、1区間の可能なSTFTを上下で挟む。
時刻t0,t1のSTFTをu0,u1、実行P増分をm、Iの最大増減速度をI+,I-、
Pの最大増減量をP+,P-とすると、時刻tの必要条件は次のとおり。

```text
u_low(t) = max(u0 - I-*(t-t0) - m*P-, u1 - I+*(t1-t) - m*P+)
u_high(t)= min(u0 + I+*(t-t0) + m*P+, u1 + I-*(t1-t) + m*P-)
```

実装は前後のホスト読取り窓と1タスクtickも含める。BINから得た上限は
I+=0.048828125/s、I-=0.0396728515625/s、P+=0.02587890625、P-=0.01611328125。
P待ち中のI停止も許す。P方向の交互性は仮定しない。リセット・カウンタ飽和・読取りの
欠損では有限の範囲を返さない。この範囲は外側の必要条件で、全時刻の端点が一つの
DME軌跡として同時に実現できると証明したものではない。

968の燃料入力は、同じ噴射応答のSTFTでTIのラムダ成分を分離し、
残りを補間して上記のSTFT範囲を掛ける。

```text
B_b(t) = interpolate(TI_b / injectionSTFT_b) * rpm(t)/120 * cutFraction(t)
F_b_low(t)  = B_b(t) * u_b_low(t)
F_b_high(t) = B_b(t) * u_b_high(t)
```

967はTIがないため、従来のDME再構成燃料からSTFTを分離した同様の条件付き入力とする。
TIへrf_korrを重ねて掛けない。非ラムダ部分の補間、TIの量子化・内部更新順序、
実噴射燃料と指令値の差まで解決したという意味ではない。

## 同じ時刻のセル寄与と燃料量を使った検査

`ve_response_grid.py` と `analyze-command-grid.py` は100msの有限グリッド上で
`x_j(t)=H[A0*w_j](t)/H[A0](t)` と `q_b(t)=H[F_b](t)/H[A0](t)` を同時刻に結び付ける。
濃い観測では `sum(x_j(t)*f_j)+bank <= q_high(t)`、薄い観測では
`sum(x_j(t)*f_j)+bank >= q_low(t)` となる時刻が読取り窓内に必要。
I更新量から導いた継続時間制約には、必要時間の重み付き合計も課す。
セル寄与の最小値と燃料比の最大値を別時刻から組み合わせる以前の線形緩和より厳しい。

入力履歴の欠損マスクも含めて**同じ375観測**、flow-0.25-mix、読取り中央で比較:

| 入力 | 有限グリッドでの結果 |
|---|---|
| 最終TI/STFTをそのまま直線補間 | 不成立 |
| I/P更新則による燃料範囲 | 2400rpm倍率0.6118〜0.7802 |

後者は変更率−38.82〜−21.98%、VE 0.841を基準に約0.5145〜0.6562。
両端の別マップを保存し、不等式違反は7.1e-9以下。−26.2%は含むが一点にはならず、
−2.7%はこの条件では含まない。有限グリッドと入力の外側範囲の結果であり、
連続時間のDME全挙動や変更後の実車を再現した証明ではない。

輸送13仮説×読取り位置3条件の線形緩和では39条件中35条件が成立し、4条件は不成立。
成立条件の範囲の合併は0.5035〜0.8951。この合併も較正保証範囲ではなく、
未検証の輸送仮説を実測済みの誤差限界と読み替えない。

さらに `analyze-command-whole-map.py` で対象セルへの寄与による選択を外した。
代表モデルは968の8339制約、967の5681制約、共同14020制約がすべて不成立。
13輸送仮説×（968単独・967単独・共同）の39ケースも、読取り中央では39ケースとも不成立。
代表モデルの968には一つだけで探索域を超える制約はなく、組み合わせると矛盾する。
従って、上記375観測の条件付き範囲を、全ログを説明する完成したVEロジックとして
採用することもできない。この検査は入力・輸送・一定のバンク差等を含むモデル全体を
棄却するもので、実車の物理原因を一つに特定したという意味ではない。

**完了したのは−26.2%と−2.7%の差の原因特定と、比較用推定器の欠陥検出・修正である。**
単一のVE補正量の識別、変更後rf_korrのヒステリシスを含む実車整合性、ブラウザTuneへの
採用は未完。現段階で範囲の中央・上端・正則化解を「確定補正量」として書き込まない。
運転点を保持すれば解決すると仮定せず、全て動いている既存RAW履歴で検査した。


出力は `archive/response-influence/<session-id>/analysis.json` と
`archive/response-identification/all-models.json`。後者は許容範囲の両端を実現する
別マップ、上限の根拠となった観測と双対係数、ログ/BIN/ソースのSHAも保存する。
P動作を扱う結果は `archive/command-reconstruction/<session-id>/analysis.json`、
`archive/command-bounds/all-models.json`、`archive/command-bounds/grid-flow-0.25-mix.json`。
全マップ検査は `archive/command-bounds/whole-map-all-models.json`。
BIN生成も公開も行わない。未完なのは、これらの入力・輸送仮定を超える補正量の確定と、
変更後のrf_korr分岐を含めたTune計算への採用である。
