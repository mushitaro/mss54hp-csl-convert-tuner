# 50 — バイナリ系統の実測差分

素の CSL 0401 / Terra 改変 / Community Patch v1 の**バイト単位の実測差分**。
64 KB キャリブレーション領域と 1 MB フル BIN の両方で比較した結果。

比較に使ったファイル:

| 呼称 | ファイル |
|---|---|
| 素の CSL（PD11） | `211325000401PD11.bin`（64 KB パーシャル） |
| 素の CSL（JP 読み出し） | `CSL_jp.bin`（64 KB パーシャル） |
| Terra | `Full 211323000401PD31_TERRA.bin`（1 MB） |
| CP v1 | `211323000401PD31_Community_Patch_v1.bin`（1 MB）／`…_Partial.bin`（64 KB） |

> **`Full 211323000401PD31_TERRA.bin` ＝ `Full 211323000401PD31_repair.bin` ＝
> `2113230401_Alternator.bin` は完全同一バイト。**

### `rf_p_saug` DS2 修正の中身

Terra 側は payload バイトに**真偽値**（`rf_p_saug > 8 ? 1 : 0`）を書いていた。
逆コンパイル `decomp/master/030b84.txt:501-502`:

```c
puVar12[7] = -(8 < rf_p_saug) & 1;   /* ← 上位バイトのはずが真偽値 */
puVar12[8] = (undefined1)rf_p_saug;
```

CP v1 は `MOVE.W rf_p_saug,D0 / ASR.L #8,D0 / MOVE.B D0,(A2)+` に置き換え、**上位バイトを正しく出す**。
RAM `0xFFEECA` = `rf_p_saug` は `graph.json` のシンボルで確認済み。

→ **Terra プログラムのままだと DS2 ログの `rf_psau` チャンネルが壊れている。**

### Community Patch v1 の公式変更リスト（フォーラム原文）

| # | 変更 | 対象 |
|---|---|---|
| 1 | `GEN_ST` 信号を DME4 CAN メッセージで送出可能に（`K_GEN_CFG` / `K_GEN_TP` / `K_GEN_HYS`。**アドレスは移動している**） | 両方 |
| 2 | 排ガス検査端末との接続性修正（SIB 12 11 06） | 両方 |
| 3 | DS2 シリアルフレームの `rf_psau` 修正 | 両方 |
| 4 | プログラム ROM 版数を 32300 ブートローダ表記に | M3 版のみ |
| 5 | `K_FR_T_ADAPT` を `0x96`（1.5 s）→ `0x100`（2.56 s） | M3 版のみ |

CP v1 は 2 種類配布されている: `211325000401PD31`（CSL 32500 BL）と
`211323000401PD31`（M3 32300 BL）。**#5 は M3 版のみ**。

## 3. パーシャル BIN からの系統推定

プログラム領域はパーシャルに含まれないため断定はできないが、
以下の副次マーカーで実用的な推定ができる。

| マーカー | オフセット | 素の CSL | Terra | CP v1 |
|---|---|---|---|---|
| `K_FR_T_ADAPT` | `0xE002`–`0xE003` | `00 96` | `01 96` | `01 00` |
| `K_FGR_CONFIG` | `0x9914` | `0x63` | `0x03` | `0x63` |
| 排ガス端末レコード | `0x5844` / `0x5968` | `FFFFFF` / `FFFFFF` | `FFFFFF` / `01050A` | `xx050A` / `FFFFFF` |
| `KL_V_MAX_GANG` | `0x92C0`–`0x92CF` | `0x1020`×8 | `0x11D0`×8 | `0x11D0`×8 |

| 観測 | 推定 |
|---|---|
| `0xE002-3 = 01 96` かつ `0x9914 = 0x03` かつ `0x5968 = 01 05 0A` | **Terra 系。FRA 適応停止バグあり** |
| `0xE002-3 = 01 00` かつ `0x5844` にレコード | **Community Patch v1 系。FRA 正常（2.56 s）** |
| `0xE002-3 = 00 96` | 素の CSL。CSL(32500) BL なら正常、M3(32300) BL なら**故障コード読取不可** |

> このツールはこの判定を**実装していない**（`40-fr-adaptation-bug.md` §3 の理由）。
> 参考情報として記録しておく。

## 4. Terra が素の CSL に対して行っている変更（`CSL_jp.bin` との差分, 36 バイト / 14 区間）

`CSL_jp.bin`（日本仕様 CSL の読み出し）を基準にすると、Terra の差分は次だけ:

| オフセット | 名前 | CSL_jp | Terra |
|---|---|---|---|
| `0x0005` / `0x8005` | `K_VERS_DATEN_S/M` | `0x51` | `0x50` |
| `0x3FFC` / `0xBFFC` | CRC | `2F81` / `1158` | `4ABE` / `5607` |
| `0x5968`–`0x596A` | 排ガス端末レコード | `FF FF FF` | `01 05 0A` |
| `0x92C0`–`0x92CF` | `KL_V_MAX_GANG` | `0x1020` 系 | `0x11D0`×8 |
| `0x9914` | `K_FGR_CONFIG` | `0x63` | `0x03` |
| `0xBFBD`…`0xBFE6` | プログラム ID 文字列 | `"…5…1…"` | `"…3…3…"` |
| `0xE002` | `K_FR_T_ADAPT` 上位 | `00` | `01` |

つまり **Terra の変更は「速度リミッター解除」「クルコン設定」「ID 文字列」「FSP センチネル」だけ**で、
燃調・点火・アイドルの較正には一切手を入れていない。
問題は較正ではなく `0x25630` の命令改変にある。
